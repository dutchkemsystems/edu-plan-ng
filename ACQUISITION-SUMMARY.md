# Acquisition & Technical Due-Diligence Summary — EduPlan NG

EduPlan NG is a production-grade, acquisition-ready curriculum intelligence and lesson planning SaaS engineered specifically for Nigeria's 1.5M+ secondary school educators (JSS 1–3 and SSS 1–3). The platform transforms traditional paper-bound academic planning into an automated workflow by seeding the full national statutory NERDC curriculum (936 weekly topics across 24 core subjects), offering an intelligent lesson plan composer with 20-second autosave, 1-click 13-week Scheme of Work generation, WAEC/BECE examination and marking scheme compilation, and multilingual parent messaging in English, Yorùbá, Igbo, and Hausa. Built on a Naira-first recurring revenue model powered by Kora Pay (Monthly at ₦2,500, Annual at ₦22,000, and School District licensing at ₦45,000/year for 10 teachers), the application addresses a massive, underserved, and highly sticky market across West Africa with direct domestic card, bank transfer, and USSD payment clearing.

From an engineering due-diligence standpoint, the codebase is architected as an ultra-lean full-stack TypeScript project pairing a high-performance React 19 / Vite 8 client with an Express 4.21 API proxy and Drizzle ORM over LibSQL/SQLite, achieving sub-100ms cold starts, sub-60KB gzip bundle footprint, and 100% WCAG 2.1 AA accessibility. The repository exhibits elite software engineering discipline: 0 raw `console.log` statements in production code in favor of an ISO-timestamped structured JSON logger, zero hardcoded secrets, 8 formal Architecture Decision Records (ADRs), CycloneDX SBOM generation (`sbom.json`), multi-stage Alpine Docker orchestration, and comprehensive GitHub Actions CI/CD workflows covering CodeQL, dependency review, and OpenSSF Scorecard compliance. For AI data acquirers and foundation model teams, the codebase constitutes an unprecedented, highly structured dataset of verified African pedagogical standards, curriculum topic hierarchies, Bloom's cognitive taxonomy mappings, and localized bilingual educational dialogues.
