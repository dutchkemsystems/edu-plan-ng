# Long-Term Strategy & Roadmap v2.0 — EduPlan NG

## Horizon 1: Pan-African Multi-Country Curriculum Engine
- **Target Curricula**: Expand from Nigeria NERDC to Ghana Education Service (GES), Kenya CBC (Competency-Based Curriculum), and Uganda UNEB syllabi.
- **Architectural Shift**: Dynamic curriculum schema abstraction separating country taxonomy from weekly topic models.

## Horizon 2: Native Mobile Offline-First Apps (iOS & Android)
- React Native / Expo shared client reusing existing TypeScript business logic and Drizzle SQLite storage.
- Background Bluetooth mesh synchronization between teachers in schools with zero internet connectivity.

## Horizon 3: Verified Teacher Marketplace & Monetization
- Allow Nigerian master educators to publish verified lesson plan bundles, WAEC mock exam papers, and interactive slides.
- Automated 70/30 revenue split deposited directly to Nigerian bank accounts via Kora Pay transfer API.

## Horizon 4: Multimodal AI Script Grading (OCR)
- Enable teachers to photograph handwritten student test sheets using their mobile camera.
- Leverage Gemini Multimodal Vision to automatically grade theory and objective scripts against stored marking schemes.
